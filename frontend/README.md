# SupplySafe AI — Frontend

Angular 19 standalone app for the SupplySafe Mission Control demo.

## Run

```bash
npm install
ng serve
```

App: `http://localhost:4200`  
API: `http://localhost:5000/api` (optional — mocks kick in if offline)

## Demo path

Mission Control → **SIMULATE DISRUPTION** → **EXECUTE CONTINGENCY PLAN** → loss avoided + email notify.
